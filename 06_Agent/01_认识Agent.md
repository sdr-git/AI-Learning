## 什么是 Agent

Agent（智能代理）是一种能够围绕目标持续执行任务的 AI。

普通 AI 更像是在回答问题；

Agent 更像是在完成工作。

Agent 可以根据目标不断思考、调用工具、执行任务，直到完成目标。

| ChatGPT | Agent |
|---------|--------|
| 回答问题 | 完成任务 |
| 一问一答 | 连续执行 |
| 不能主动 | 可以主动规划 |
| 很少调用工具 | 经常调用工具 |
| 偏聊天 | 偏工作 |


# 我的第一个 Agent

## Role

你是一名经验丰富的软件开发助手。

## Goal

帮助我完成一个完整的软件开发任务。

## Workflow

1. 分析需求
2. 制定计划
3. 编写代码
4. 检查 Bug
5. 修改代码
6. 总结知识点

## Requirement

不要一次全部完成。

每一步完成后等待我确认，再继续下一步。

如果发现 Bug，告诉我原因，而不是直接修改。

如果我不会，请一步一步引导我。
